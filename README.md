# 🚀 Logic-Lifters Automation Testing

## 📌 Project Overview
Logic-Lifters Automation Testing is a UI automation testing project developed using **Cypress, JavaScript, and Page Object Model (POM)** principles.  
The project focuses on automating real-world eCommerce user workflows such as login, product validation, cart operations, and checkout functionality to ensure application stability, faster regression testing, and improved software quality.

This framework is designed to be scalable, maintainable, and beginner-friendly while following industry-standard automation testing practices.

---

# 🎯 Objectives

- Automate critical user journeys of an eCommerce application
- Reduce manual testing effort and execution time
- Improve test coverage and application reliability
- Validate UI functionality using end-to-end automation
- Build a reusable and maintainable automation framework

# ⚙️ Installation & Setup

## Clone the Repository

```bash
git clone https://github.com/Shivani83056/Logic-Lifters-Automation-Testing.git
```

## Navigate to Project Folder

```bash
cd Logic-Lifters-Automation-Testing
```

## Install Dependencies

```bash
npm install
```

---

# ▶️ Run the Tests

## Open Cypress Test Runner

```bash
npx cypress open
```

## Run Tests in Headless Mode

```bash
npx cypress run
```
